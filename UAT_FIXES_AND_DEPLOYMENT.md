# UAT Fixes and Deployment Guide

## Critical Issues Found During UAT Testing

### 1. Backend 500 Errors (CRITICAL - BLOCKING ALL FEATURES)

**Problem:** Backend API is returning "Internal Server Error" (500) for ALL endpoints, including:
- `/api/auth/register` (groomer registration)
- `/api/customer/register` (customer registration)
- `/api/shops` (browse groomers)
- `/api/customer/pets` (pet management)

**Root Cause:** Likely one of:
1. Database connection failure
2. Missing environment variables on Render
3. Backend service crashed/not running
4. Database tables not initialized

**Fix Steps:**

#### Step 1: Verify Render Service Status
1. Go to https://dashboard.render.com
2. Navigate to the `petcarebooker-api` service
3. Check if service is running or crashed
4. If crashed, check logs for error messages
5. If service is sleeping (free tier), trigger a manual deploy to wake it up

#### Step 2: Update Environment Variables on Render
The `render.yaml` has been updated with all required environment variables. You need to ensure these are set in the Render dashboard:

**Required Environment Variables:**
```
ENVIRONMENT=production
PYTHON_VERSION=3.11.9
DATABASE_URL=<auto from database>
SECRET_KEY=<auto-generated or manual>
JWT_SECRET=<generate with: openssl rand -hex 32>
FRONTEND_URL=https://www.petcarebooker.com
FROM_EMAIL=PetCareBooker <noreply@petcarebooker.com>

# Optional but recommended:
RESEND_API_KEY=<your resend api key>
TWILIO_ACCOUNT_SID=<your twilio sid>
TWILIO_AUTH_TOKEN=<your twilio token>
TWILIO_PHONE_NUMBER=<your twilio phone>
STRIPE_SECRET_KEY=<your stripe secret key>
STRIPE_WEBHOOK_SECRET=<your stripe webhook secret>
```

**How to Set:**
1. Go to Render Dashboard → petcarebooker-api service
2. Click "Environment" tab
3. Add missing variables (especially `ENVIRONMENT=production`)
4. Click "Save Changes"
5. Service will automatically redeploy

#### Step 3: Verify Database Connection
1. Go to Render Dashboard → Databases
2. Find `petcarebooker-db`
3. Ensure it's running and accessible
4. Check that DATABASE_URL is correctly linked to the web service

#### Step 4: Initialize Database Tables
The database tables should be auto-created by SQLAlchemy when the app starts. If they're not:

1. Connect to your Render PostgreSQL database using the provided connection string
2. Run the migration if needed:
   ```sql
   -- Check if tables exist:
   SELECT table_name FROM information_schema.tables 
   WHERE table_schema = 'public';
   ```

3. If tables don't exist, the backend should create them automatically on next startup

#### Step 5: Trigger Manual Deploy
1. In Render Dashboard → petcarebooker-api
2. Click "Manual Deploy" → "Deploy latest commit"
3. Wait for deployment to complete
4. Check logs for any errors

#### Step 6: Test Backend Health
Once deployed, test these endpoints:
```bash
# Root endpoint
curl https://petcarebooker.onrender.com/

# Get shops (should return empty array or shops)
curl https://petcarebooker.onrender.com/api/shops

# Health check (if implemented)
curl https://petcarebooker.onrender.com/health
```

If still getting 500 errors, check Render logs:
```bash
# In Render Dashboard, go to:
# petcarebooker-api → Logs tab
# Look for Python tracebacks or error messages
```
