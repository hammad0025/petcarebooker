## 🎯 On-Page SEO Optimization Checklist

### For Existing Pages:
- [ ] Add target keyword to H1 tag
- [ ] Include keyword in first 100 words
- [ ] Use keyword in at least one H2/H3
- [ ] Add internal links to related content
- [ ] Optimize meta descriptions (155-160 chars)
- [ ] Add schema markup (LocalBusiness, FAQPage, HowTo)
- [ ] Include location-specific content
- [ ] Add FAQ section with target keywords
- [ ] Optimize images with alt text
- [ ] Ensure mobile responsiveness

### For Blog Posts:
- [ ] Target 1 primary keyword + 2-3 related keywords
- [ ] Write 1,500-2,500 words (comprehensive content)
- [ ] Include table of contents for long posts
- [ ] Add internal links (3-5 per post)
- [ ] Include external links to authoritative sources
- [ ] Add images with descriptive alt text
- [ ] Include CTA to book groomer
- [ ] Add related posts section
